# POWER ACCESS — Social Phishing Awareness Demo

A static, mobile-friendly cyber-safety training page that demonstrates common social-engineering warning signs.

## Safety by design
- Clearly labelled as a training simulation throughout.
- Does not imitate the real Instagram login page.
- Has no username, password, OTP, or credential submission fields.
- Does not collect, transmit, or store visitor data.
- Uses no tracking, cookies, external scripts, or backend.

## Deploy
This is a static site. Import this repository into Vercel and deploy with the default settings (no build command and no output directory required). The page is served from `index.html`.

## Test
Open the deployed URL on a phone. Tap **View the simulated link**, then **Show me the warning signs**, and finally **Restart demo**.

This project is for awareness training only. Do not use it to impersonate services or collect credentials.
